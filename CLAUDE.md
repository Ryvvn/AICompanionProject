# Output Locations

## Key Files
The following files are crucial for the operation and configuration of the Bananalyzer project:
1. **src/bananalyzer/__main__.py**: This file serves as the main entry point for the CLI application. It imports the `app` from `bananalyzer.cli` and defines the `main()` function to run the application.

2. **src/bananalyzer/config.py**: Contains the configuration settings for the application. It defines the `Settings`, `ModelProfiles`, and `Thresholds` classes using Pydantic for loading from YAML files. This enables the project to maintain structured settings and profiles for various models and parameters.

3. **src/bananalyzer/constants.py**: Sets up the basic directory structure for the application, including paths for configuration, state, logs, memory, and prompts. It defines canonical state values (like CODING, GAMING, etc.) for managing application states.

## BMAD Output Locations
The outputs generated by BMAD can be found in the following locations:
- **Implementation Artifacts**: Located in `_bmad-output/implementation-artifacts/`. This folder contains the implementation-related outputs from BMAD.
- **Planning Artifacts**: Found in `_bmad-output/planning-artifacts/`. This folder includes the planning documents and related outputs.

# FAQs and Troubleshooting
- **Q**: What if I encounter errors while running commands?  
  **A**: Ensure you have the proper permissions set in `settings.json`. Check the logs for detailed error messages.
- **Q**: How to revert changes made by BMAD?  
  **A**: You can restore from previous commits or manually adjust output files.
